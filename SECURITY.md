# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.3.x (latest release) | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer can see the report.

This extension deletes files. Reports about deleting more than a rule allows, deleting outside the configured folder, or the handling of the API token are especially welcome.

Do not include real credentials, personal data, production logs, or confidential infrastructure details in a report.
