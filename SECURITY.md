# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.4.x (latest release) | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer can see the report.

This extension deletes files. Reports about deleting more than a rule allows, deleting outside the configured folder, the handling of the API token, or the automatic printer run (what it does with the operator role on a printer) are especially welcome.

Do not include real credentials, personal data, production logs, or confidential infrastructure details in a report.
